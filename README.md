# 🌍 Wanderlust

A full-stack travel listing web application where users can explore,
create, edit and review travel listings.

## 🚀 Features

- 🔐 User Authentication
- 🏠 Create and manage listings
- ✏️ Edit and delete listings
- ⭐ Reviews and ratings
- 📸 Listing images
- ⚠️ Error handling
- 📱 Responsive UI

## 🛠️ Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- Bootstrap
- JavaScript
- HTML & CSS
